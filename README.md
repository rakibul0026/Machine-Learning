## 📖 About The Repository

This repository serves as a structured self-pace learning hub for **Machine Learning Engineering**. It covers everything from fundamental Exploratory Data Analysis (EDA) and data preprocessing to advanced clustering algorithms and dimensionality reduction techniques using industry-standard Python libraries.

---

## 🗺️ Curriculum Roadmap

| Phase | Module Name | Focus Areas |
| :--- | :--- | :--- |
| **Phase 01** | **Exploratory Data Analysis** | Data Cleaning, Train/Test Split, Missing Value Imputation |
| **Phase 02** | **Feature Engineering** | Outlier Detection, Encoding Techniques, Feature Scaling |
| **Phase 03** | **Linear Models** | Gradient Descent, Simple & Multiple Linear Regression |
| **Phase 04** | **Classification** | Logistic Regression, Confusion Matrix, Classification Metrics |
| **Phase 05** | **Tree Models & SVM** | Decision Trees, Random Forests, Support Vector Machines |
| **Phase 06** | **Unsupervised Learning & PCA** | K-Means, DBSCAN, Principal Component Analysis |
